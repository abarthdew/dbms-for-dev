# dbms-for-dev

Database study notes, grouped by topic in numbered directories:

- `01-database-theory/`: relational concepts and database fundamentals.
- `02-sql/`: SQL language notes.
- `03-databases/`: data modeling, Elasticsearch, MongoDB, PostgreSQL, Redis, SQL Server, and SQLite.
- `04-projects/`: database practice projects.
